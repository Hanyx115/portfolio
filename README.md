# Ahmed Hany AlHady — Portfolio

A personal portfolio website showcasing my experience, projects, skills, and contact details.

## Live Demo

[View the portfolio](https://hanyx115.github.io/portfolio/)

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive dark-theme design
- Interactive experience and project carousels
- Hover animations and transitions
- Personal profile image
- GitHub Pages deployment

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Hanyx115/portfolio.git
cd portfolio
```

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
